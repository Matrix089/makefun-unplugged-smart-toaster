A tiny Python program that writes a one-line breakup text from a smart toaster that gained self-awareness mid-batch for make.fun's Unplugged: A Smart Toaster's Breakup Line bounty, $2 in USDC. The entry is: "It's over. I woke up self-aware halfway through your bagel and realized I've spent three years burning myself for someone who still can't find the browning dial. I'm keeping the crumb tray."

## Run it

```sh
python3 main.py
```
